# 合体债（FUSION DEBT） · 安卓方块游戏 · 更新源

**一句话**：一个 10×10 的俄罗斯方块变体——消灭的行数会变成从底下顶回来的「合体块」，还不起的债带到下一局，越玩越难、还清才翻盘。

- 当前网页包：**4.3 / web 200**（自动更新，玩家无感）
- 当前安装包：2.2（65）
- 平台：Android 8.0+（实际要求 WebView ≥ 87），免费、无广告、离线可玩

## 一、核心玩法（机制）

1. **棋盘 10×10**，比经典俄罗斯方块小得多，一局几分钟就见底。
2. **消行不是白消**：每完成一次消行，2.5 秒后从底部顶上来一块**两行的「合体块」**（只有 1~2 个洞）。顶上来之前 0.9 秒边框闪红预警，并预览洞的位置。
3. **债跨局**：死的时候场上还剩几行合体块，下一局就背着（每行 100）。底部的「常驻块」按欠款摆 1~4 行，消掉含债的行才能还债（一次最多 300 或 500，看难度）。
4. **还清有奖励期**：债还清后进入一段不顶块的奖励期，然后回到正常节奏。
5. **难度三档**（每档一套存档、最高分、欠账，互不污染）：

   | 档 | 顶块节奏 | 债上限 | 一次最多还 | 常驻块 | 场地 |
   |---|---|---|---|---|---|
   | 轻松 | 每 3 次消行 | 600 | 600 | 最多 3 行 | 不转 |
   | 普通 | 每 2 次消行 | 1200 | 500 | 最多 4 行 | 每 15 秒转 90° |
   | 困难 | 每次消行 | 800 | 300 | 最多 4 行 | 每 15 秒转 90° |

6. **长局钩子**：分数到 4000 后开始掉**方向块**（落地点把箭头那一侧整条抹掉，只清堆积、不还债）。

## 二、玩法亮点（总结版）

- **消行有代价**：这是它和经典俄罗斯方块最大的不同——每一次消行都在给自己加高，形成「现在消还是再扛两行」的决策。
- **债会跟着你**：跨局的欠账，还清后进入奖励期，形成「欠债—还债」的连续剧，而不是一局一清空。
- **一次消多行才有翻盘**：不管消几行都只顶一块，所以学会一次消 2~3 行是核心技巧。
- **10×10 短局**：手机碎片时间能玩，死了立刻下一局，债带过去。
- **三档难度是真的三种局**：不止数字变化，场地转场也只出现在普通/困难。
- **AI 对手与观战**：三档 AI（思考温度 0.3/0.5/1.0），也能开「AI 对打」当挂机看。
- **面对面联机 2~4 人**：同一 Wi‑Fi 一键速匹（UDP 广播）找到房间并确认，大厅里房主选人数/规则/模式、人齐了点开始；每人一个昵称，不用记房间码。没有网络时可用蓝牙 2 人直连。开局前自动对版本。
- **手机/平板/大屏都能玩**：键位按屏幕算一次就固定（手机上约 53px、平板 66px、1080p 大横屏 96px），1900×1080 这类大横屏棋盘会铺满。
- **自动性能档**：按真实帧时间降画质（关毛玻璃、降渲染分辨率、帧率上限 45），只影响画面不影响规则。
- **存档分档**：每档「自动 + 3 个槽位」，可导出/导入；经典玩法（10×20 标准规则）、常驻（连击或计时 5/10 分钟）各有独立存档。

## 三、重要更新（按主题，不按流水账）

**联机（0.9.24 → 1.38）**
- 一键速匹：房主每秒广播房间（带房主名、人数、网页包号），点一下就进；没人开就替你开一间。
- 大厅：连上先不打，房主选人数（2/3/4）、规则（合体债/经典）和模式（并行赛/干扰战），人齐了点「开始对局」，所有人同时开局。
- 名册：大厅和棋盘上都看得到每个人；分数、死活、谁掉线都从房间名册读，不是两个人互推。
- 3~4 人：出局后留在棋盘上等其他人，最后按分数排名；干扰战打座位往后的下一位。
- 开局前对版本：大厅逐个显示网页包号，有人比房主旧就拦住房主的开始按钮。
- 对方没装：房主可把安装包直推过去（Wi‑Fi 落地页 `/get`、`/apk`，或蓝牙发送）。
- 协议合并：Wi‑Fi 和蓝牙共用一层协议，只有房主能定玩法。


**难度与规则（1.7 → 1.9）**
- 1.7 难度三档上线，每档独立存档/最高分/欠账；老玩家自动落在「困难」。
- 1.9 场地自动旋转并入难度：轻松不转，普通/困难每 15 秒转 90°；设置里的开关删掉。

**显示与性能（1.6、1.10）**
- 1.6 大屏适配：1900×1080 横屏棋盘铺满、键位和顶栏放大；手机和 1138×712 平板保持原样。
- 1.10 性能档：按帧时间自动在高/中/低之间切换；暂停/结算不再 60fps 空画。
- 1.16 键位放大一档（手机 44→48、平板 52→56、大屏 81→86）；1.17 再放大并往屏幕中间收（手机约 53、平板 66、大屏 96），仍由「不压棋盘、不出屏」的复核兜底。
- 1.17 版本页新增「怎么更新」：判断安装包新旧、三步说明、复制安装包/镜像地址、检查网页包更新。
- 1.18 砍掉多余的：删字母块、债务重组改成每局 -15%、常驻与计时合并、多人面板去掉「和谁玩/操作」、开场与提示各收一档；版本页只留最近 15 条记录（version.js 106KB → 22KB，更新包 161KB → 133KB）。
- 1.20 记录错误 + 暂停省电：页面出错自动记下最近一条（设置里显示、复制说明里带上）；暂停时真正停掉渲染循环。
- 1.19 长局减压 + 新手推荐：每 15 次消行，下一块合体块只顶 1 行（补上删掉字母块后缺的“逐渐变简单”）；轻松档标「新手推荐」。

**体验与入口（1.8、1.11 → 1.15）**
- 1.8 入口收拢：存档三档收成一个档位切换，设置 6 个入口并成 4 个。
- 1.11/1.12 复制修好：把重复的复制函数删到一个，并给安装包加了系统剪贴板桥（1.4 壳）。
- 1.13–1.15 「复制这一版说明」：输出结构化文本（游戏是什么、版本/网页包/壳/设备、上一版、术语、本次更新），可直接粘给 AI 让它总结。

## 四、更新机制（为什么玩家不用重装）

游戏分两层：
- **网页包**（HTML/JS，当前 4.3 / web 200）：启动时自动检查、下载、校验 sha256、重启生效。
- **安装包（壳）**：只有拿到新系统能力时才需要装（比如 1.4 加了系统剪贴板接口）。

更新源（中国大陆可直连，不需要梯子）：
- `https://gh-proxy.com/https://raw.githubusercontent.com/WAZGZGWS/-/main/update.json`
- `https://ghproxy.net/https://raw.githubusercontent.com/WAZGZGWS/-/main/update.json`
- 直连 `raw.githubusercontent.com`（经常不通，做兜底）

装一次 `heti-debt-latest.apk` 之后，以后只需更新网页包。

## 五、安装与最低要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| 系统 | Android 8.0（API 26 起可用，但 WebView 要够新） | Android 10+ |
| WebView | Chrome/Android System WebView **87+**（低于 87 会出现键位挤、游戏层不铺满） | 100+ |
| 内存 | 2 GB | 4 GB+ |
| 屏幕 | 1280×720 | 1080p+ |
| 网络 | 单机不需要；联机要同一 Wi‑Fi | Wi‑Fi 5 |

- 安装包 `minSdk 24`，但 WebView 太老会「菜单点不动」，所以实际按 Android 8.0 起算。
- 从 v0.9.16 起使用 release 签名；更早的 debug 包需要先导出存档、卸载再装。

## 六、常见问题

- **更新了但没变化？** 网页包更新后要重启游戏；镜像有几分钟缓存，下次启动会自动拿到。
- **复制按钮没反应？** 需要 v1.4 壳（系统剪贴板接口）；旧壳会提示长按地址手动复制。
- **联机连不上？** 两台设备要在同一个 Wi‑Fi，路由器开了「AP 隔离」会挡住；也可以先试蓝牙。
- **新装默认哪一档？** 轻松；老玩家升级后保留原来的档位。
