## 玩法亮点

- **消行不是白消**：每消一行，2.5 秒后底下顶上来一块「合体块」——占两行、只留 1~2 个洞。最后 0.9 秒顶部闪红预警。
- **债会跟着你**：死的时候场上还剩几行合体块，下一局开局就背着（左下角 `-500` 这种）。底部按欠款摆 1~4 行常驻块，消行能还债（每次最多 300）；还清后 18 次消行不顶块。
- **场地会转（可选）**：设置里打开后每 15 秒顺时针 90°、落沙；**默认关闭**。
- **方向块**：4000 分后开始掉，落地把箭头那一侧整条抹掉；只清堆积，不直接还债。
- **字母块**：第 40 次消行后合体块变形，标出这次抽到哪个字母。
- **一局很短**：10×10 小盘，几分钟一局；死了直接下一局，债带过去。
- **能存档**：每个模式（单人 / 经典 / 常驻）各有自动存档 + 3 个手动槽，可导入导出。
- **打 AI / 联机**：三档 AI，带思考温度（0.3 / 0.5 / 1.0），落子间隔 2/3/5 秒一块；同一 Wi-Fi 联机，可选「合体债 / 经典」规则，并行赛或干扰战（经典只开并行赛）。
- **三种玩法、三套存档**：合体债、经典玩法（10×20 标准计分）、常驻（10×10 连击、轻松）；存档分开叫「单人玩法1-3」「经典玩法1-3」「常驻玩法1-3」。
- **AI 观战**：两个困难温度 AI 自己打（0.5 秒一步，会算合体块代价，平均活 100+ 步），一局完自动下一局，玩累了可以挂着看。
- **手机友好**：竖屏左手方向/右手动作，横屏左右手各一边；设置里可选「屏幕方向」（跟随系统 / 自动旋转 / 横屏 / 横屏反向 / 竖屏）。系统不转屏时页面会把画面自己转 90°，并显示当前方向和安装包版本；网页包静默自动更新。
- **握手开场**：联机双方就绪后「你 / 我」从左右撞到中间、散开显出「决一死战」，随后游戏界面淡入。
- **AI 自动档**：按本机算力（核数/内存/GPU/刷新率/分辨率）自动选简单/普通/困难，抽屉里显示分数。
- **上次对手一键继续**：局域网记住上次房间，蓝牙记住上次配对的设备，面板上直接继续。
- **蓝牙连接修复**：房主不会因为一次失败就关房；开房/加入的状态和失败原因直接显示在抽屉里。
- **蓝牙对打**：多人面板「蓝牙对打（无网）」；两台安卓系统配对后，一台开房、一台加入，不需要 Wi-Fi/流量。
- **覆盖安装不丢存档**：新 APK 覆盖旧包安装，自动把自带网页包同步到 files/web；更新前提醒先保存/导出。
- **开始页只写版本号**：不写更新内容；首次进首页弹 3 秒玩法引导，详细模式说明在「版本与更新」。
- **禅模式**：常驻抽屉里选 5/10 分钟，10×12、堆满自动整理不会死；暂停/后台停表，自动存档带剩余时间。
- **设置也收起来**：设置页只留「游戏 / 屏幕方向 / 声音与震动 / 设备信息」四个入口，点开右侧抽屉再调。
- **菜单收起来**：玩法页只留「主玩法 / 常驻 / AI / 多人」，主玩法和 AI 点开右侧抽屉再选子项，减少一屏选项。
- **常驻模式**：10×10、不背债、不顶合体块，连续消行叠连击倍数（最高 x2.25），3 块没消才断；和单人/经典一样有自动存档 + 槽位 1~3。
- **声音更大、可调**：提示音总线 0.9×音效 3.2 + 压缩器；设置里音量「小/中/大」，蓝牙耳机不用开到最大。
- **分数与债务更清楚**：一万以上显示「1.2万」；右侧「结束欠」实时算进场上合体块；顶块前 2.5 秒预警并预览洞位；常驻块按欠款 1~4 行，债务封顶 800。
- **存档分开管**：单人玩法/经典玩法各 4 个位置（自动 + 槽位 1~3），可以只删不想要的那一档，清空全部要二次确认。
- **旧壳会被催装**：检测到安装包版本低于 v0.7.8 时，进游戏弹一次提示，自动把新版 APK 地址放进剪贴板，并显示可长按复制的输入框；设置里也常驻「复制新版 APK 下载地址」。

## 和经典俄罗斯方块的改动

> 「原版」按最常见的 10×20、消行得分、随等级加速来比；不同版本（Guideline / NES / GB）细节本来就不一样。

| 项目 | 经典原版 | 合体债 | 为什么改 |
|---|---|---|---|
| 棋盘 | 10×20 | **10×10** | 一局更短，合体块更快逼到顶 |
| 消行 | 消掉就没了，得分 | 消掉后**顶 2 行合体块**（1~2 个洞） | 让「消行」本身有代价，不只是收益 |
| 跨局 | 每局独立 | **债**：死时「没还完的债 + 场上合体块行数×100」带到下一局；常驻块还债 | 连败有压力，还清有翻盘 |
| 速度 | 随等级加快 | **固定 1 秒/格**，软降 20 格/秒 | 手机短局，不靠手速堆难度 |
| 场地 | 不动 | **可选的 15 秒 90° 旋转 + 落沙**（默认关） | 加变数；怕晕可以关 |
| 特殊块 | 无 | **方向块**（1000 分后）、**字母块**（第 100 次消行后变形） | 后期不只拼手速 |
| 计分 | 按行数递增 | 每行 600 + 每次消行 600（1 行 1200、4 行 3000） | 鼓励多行一起消 |
| 死亡 | 顶出 | 顶出，或合体块顶不上来 | 两种死法 |
| 暂存 | 现代版有 | 有（C 键 / 暂存按钮） | — |
| 联机 | 原版没有 | 同 Wi-Fi 并行赛 / 干扰战 | 手机面对面玩 |
| 更新 | 装一次就不变 | 网页包静默自动更新 | 发出去还能修 |

## 优缺点

**优点**

- 每一消都有长期代价 → 要算「现在消还是再等两行」，比原版多一层决策
- 债跨局 → 有 roguelike 式「越欠越难、还清就爽」
- 10×10 + 合体块 → 节奏快，手机上一局几分钟
- 方向块 / 字母块 / 可选旋转 → 后期有变化，不是纯堆速度
- 干扰战把消行变成攻击，面对面联机有互动
- 离线可玩、静默更新；旧手机（Android 8+）也能跑

**缺点 / 代价**

- **学习曲线陡**：合体块、债、常驻块、奖励期，得玩几局才懂；教程只讲一遍
- **单行消是净亏**：顶 2 行（约 18~19 格），新手很容易越消越死
- **债会滚雪球**：连败时开局就背 `-500~-700`，容易卡在还债期
- **没有随等级加速**：玩惯原版的人会觉得后期不够刺激
- **10×10 空间小**：高手可能觉得施展不开，四行消也难
- **不是标准俄罗斯方块**：手感（踢墙、锁定、计分）和 Guideline/SRS 不一样，玩惯的人会觉得「不对」
- **联机只有同一 Wi-Fi**：没有在线匹配、没有排行
- **场地旋转**：即使默认关，开了也容易看晕（落沙会改变堆形）
- **平台限制**：只有 Android 8.0+ / WebView 66+ 的安装包；没有 iOS 版、没有上架商店

**适合谁**：喜欢短局、能接受「越玩越难」、想和朋友面对面联机的；手机碎片时间玩的。

**不适合谁**：只想打标准俄罗斯方块、追求官方排行、或者不想算债的。

## 怎么装

**从 v0.6.5 起才会自动更新。v0.5 及更早版本没有内置更新器，必须手动装一次最新 APK（当前 v0.7.8）。**

固定下载地址（永远指向最新版，转发这个链接就行）：

- 镜像：https://gh-proxy.com/https://raw.githubusercontent.com/WAZGZGWS/-/main/heti-debt-latest.apk
- 备用：https://ghproxy.net/https://raw.githubusercontent.com/WAZGZGWS/-/main/heti-debt-latest.apk
- 原始：https://github.com/WAZGZGWS/-/raw/main/heti-debt-latest.apk

步骤：

1. 手机浏览器打开上面任意一个，下载 `heti-debt-latest.apk`（当前 v0.8.1，128,519 字节）；
2. 点开安装，第一次要允许「安装未知应用 / 未知来源」；
3. **直接覆盖安装，不要卸载**：包名和签名跟 v0.5 一样，存档和设置会保留。
   只有提示「签名不一致」时才需要卸载旧版（会丢存档）；
4. 装完打开，约 1 秒后会自动检查并更新到最新网页包；以后不用再管安装包。

## 最低要求的安卓手机

| 项目 | 最低 | 推荐 |
|---|---|---|
| 系统 | Android 8.0（API 26） | Android 10 及以上 |
| WebView 内核 | Chrome / Android System WebView 66+ | 100+ |
| 内存 | 2 GB | 4 GB 及以上 |
| 可用存储 | 50 MB | 200 MB |
| 屏幕 | 5.5 英寸，1280×720，竖屏 | 6 英寸以上，1080p+ |
| 刷新率 | 30 Hz（设置里可锁 30 帧） | 60 Hz 及以上 |
| CPU | 任意 ARM / ARM64 / x86（APK 不含 native 库） | — |
| 网络 | 单机不需要；更新和联机才用 | Wi-Fi 5 |
| 谷歌服务 | 不需要 | — |

补充说明：

- 安装包的 `minSdk` 是 24（Android 7.0），但游戏用了 `async/await` 等语法，
  **WebView 内核低于 Chrome 55 时主脚本解析不了，菜单会点不动（看着像白屏）**；
  国产 ROM 的 Android 7 往往停在 Chrome 51，所以实际按 **Android 8.0 起**算。
- Android 8/9 如果从没更新过 WebView，也建议先去应用商店把
  「Android System WebView」或 Chrome 更新到最新版。
- 联机要求两台设备在**同一个 Wi-Fi**；路由器开了「AP 隔离」会连不上。

## 怎么更新

1. 打开游戏约 1 秒后自动检查，有新版就自己下载、校验 sha256、重启进新版；
2. 更新完首页会提示「已自动更新到 vX（网页包 N）」；
3. 「更多 → 版本与更新」里能看到当前版本、每个版本改了什么，也能手动检查更新；
   更新包自带这次改动的说明，更新完首页提示会显示第一条。
4. 玩联机时，如果房主的版本比你新，**加入前会自动把房主那一版同步过来**（包括代码和规则改动），
   同步失败就不进房间，避免两边规则对不上。

中国大陆直连 `raw.githubusercontent.com` 经常不通，APK 里已经内置了
`gh-proxy.com` / `ghproxy.net` 镜像并按顺序自动切换，**不需要梯子**。
GitHub 的 CDN 有缓存，刚发布后几分钟内可能还拿到旧清单，下次启动就会更新。
